# JUnit 5 Hands-On

## Exercises Covered

### Exercise 1 - Setting Up JUnit
- Created a Maven project.
- Added JUnit 5 dependency.
- Created and executed a sample test.

### Exercise 2 - Writing Basic JUnit Tests
- Created a Calculator class.
- Wrote unit tests for add(), subtract(), and multiply() methods.

### Exercise 3 - Assertions in JUnit
Used the following assertions:
- assertEquals()
- assertTrue()
- assertFalse()
- assertNull()
- assertNotNull()

### Exercise 4 - Arrange-Act-Assert Pattern
- Used the Arrange-Act-Assert (AAA) testing pattern.
- Used @BeforeEach and @AfterEach annotations.

## Technologies Used

- Java 21
- Maven
- JUnit 5

## How to Run

1. Open the project in IntelliJ IDEA.
2. Wait for Maven dependencies to download.
3. Right-click `src/test/java`.
4. Click **Run Tests**.
5. Verify that all tests pass successfully.
