# Mockito Hands-On

## Exercises Covered

### Exercise 1 - Mocking and Stubbing

- Created a mock object using Mockito.
- Stubbed the `getData()` method to return predefined data.
- Verified the returned value using JUnit assertions.

### Exercise 2 - Verifying Interactions

- Verified that the mocked object's `getData()` method was invoked.

## Technologies Used

- Java 21
- Maven
- JUnit 5
- Mockito

## How to Run

1. Open the project in IntelliJ IDEA.
2. Wait for Maven dependencies to download.
3. Run `MyServiceTest`.
4. Verify that both tests pass successfully.
