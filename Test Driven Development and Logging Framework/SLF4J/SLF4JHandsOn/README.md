# SLF4J Hands-On

## Exercise Covered

Logging Error Messages and Warning Levels

## Technologies Used

- Java 21
- Maven
- SLF4J
- Logback

## Files

- LoggingExample.java

## Logging Levels Demonstrated

- INFO
- WARN
- ERROR

## How to Run

1. Open the project in IntelliJ IDEA.
2. Wait for Maven dependencies to download.
3. Run `LoggingExample.java`.
4. Observe the log messages in the console.
